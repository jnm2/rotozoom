# rotozoom

A WebGL recreation and extension of Antoni Gual's 9-line QBasic rotozoomer (Rel's 9 LINER contest, QBASICNEWS.COM, January 2003).

Open `index.html` in a browser. Presets:

- **ROTOZOOM.BAS**: the original (AND, default SCREEN 13 palette, 320x200, integer math).
- **ROTOZOOM (jnm2 mod)**: XOR with a red-black-green palette.
- **Mandala**: XOR across 7 axes.

`ROTOZOOM.BAS` is the original program, adapted for QB64.
